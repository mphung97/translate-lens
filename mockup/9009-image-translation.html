Design notes

Monospace by default — the 9009 theme was born inside a typing test, so the lens speaks the same quiet, keystroke-heavy language. JetBrains Mono for text, Space Grotesk for UI.

One accent does all the work. The caret green marks detection, the active mode and the primary action; everything else stays paper and ink.

Image-first workflow. Paste or upload an image, OCR extracts Chinese text, then translate to Vietnamese. The manual input is a fallback for when you have the text already.

The toolbar is the app — grip, always-on-top, mode switch, settings and close are identical on macOS and Windows. No chrome beyond what the popup needs.
